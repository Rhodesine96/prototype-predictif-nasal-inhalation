# Application de prévision commerciale
Application Streamlit, Python 3.12, app.py comme point d’entrée.

Déploiement : dépôt GitHub PRIVÉ, Streamlit Community Cloud, Python 3.12.
Copier accounts_json depuis le fichier privé SECRETS_STREAMLIT.toml dans Advanced settings / Secrets.
Les mots de passe ne figurent pas dans ce dépôt. Seules les données dont l’hébergement est autorisé doivent être déposées.
Les comptes administrateur et client restent distincts. Les exports respectent le rôle.
La visibilité de l’application est à régler selon les accès du jury.
Les annotations locales ne constituent pas un stockage durable garanti sur le cloud.
